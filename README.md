# SHOEperheroes

Static website (HTML/CSS/JS, no build step). Deploy with GitHub Pages: Settings, Pages, deploy from branch, root.

## Images to add (`assets/images/`)
| File | What |
|---|---|
| `logo.png` | Logo (square/transparent, also used as favicon) |
| `hero-before.jpg` | Muddy/dirty shoes (portrait 3:4) |
| `hero-after.jpg` | Clean shoes wearing the cover (portrait 3:4) |
| `lifestyle.jpg` | Covers in different colors (portrait 4:5) |
| `product.jpg` | Product shot (square) |
| `team-mika.jpg`, `team-alicia.jpg`, `team-vedant.jpg` | Headshots (square) |

Missing images show a labelled placeholder tile.

## Forms
Create two free forms at formspree.io and replace `YOUR_CONTACT_FORM_ID` and `YOUR_NEWSLETTER_FORM_ID` in `index.html`.
